Filtering and resampling

Butterworth and notch filters, whitening, and polyphase resampling.

GravitationalWaveData.Filtering._convolve_same — Method
_convolve_same(a, b) -> Vector{Float64}

Full linear convolution of a and b, cropped to scipy.signal.fftconvolve(a, b, mode="same")'s convention: the length(a)-sample slice of the full (length(a)+length(b)-1) convolution, centered (start = (full_len - length(a)) ÷ 2, floor division, 0-based in scipy's own formula).

GravitationalWaveData.Filtering._fir_from_transfer — Method
_fir_from_transfer(transfer, ntaps; window=:hann, ncorner=0) -> Vector{Float64}

Direct port of gwpy's filter_design.fir_from_transfer: design a length-ntaps (should be even) FIR filter realizing the given one-sided (rfft-style, DC-first) frequency-domain transfer function (here always 1 ./ asd, see whiten), via truncate -> inverse-FFT -> truncate -> circularly-shift-to-center.

GravitationalWaveData.Filtering._numpy_interp — Method
_numpy_interp(xnew, x, y) -> Vector{Float64}

1-D linear interpolation matching numpy.interp's convention: x must be sorted ascending; xnew values outside [x[1], x[end]] are clamped to the corresponding boundary y value (no extrapolation), matching what FrequencySeries.interpolate relies on.

GravitationalWaveData.Filtering._overlap_save_convolve — Method
_overlap_save_convolve(data, fir, window) -> Vector{Float64}

Direct port of gwpy's TimeSeries.convolve (overlap-save FFT convolution with edge tapering to suppress spectral leakage from the filter's settle-in transient at the two boundaries). For the segment lengths this package's whitening is normally used on (a handful of seconds to a few hundred seconds, fir a couple of seconds long), the nfft >= n/2 branch (single fftconvolve call) is what actually executes; the chunked overlap-save branch is exercised by test/runtests.jl's dedicated long-signal test (forcing n well past 8*length(fir)) checked against the single-shot path, since real whitening usage on this package's typical segment lengths never reaches it otherwise.

GravitationalWaveData.Filtering._periodic_hann — Method
_periodic_hann(n) -> Vector{Float64}

The periodic/DFT-even Hann window scipy.signal.get_window("hann", n) returns by default (fftbins=true) – distinct from DSP.Windows.hanning(n), which defaults to the symmetric convention (fftbins=false). Computed directly as 0.5*(1-cos(2*pi*k/n)) for k in 0:n-1, which is exactly a length-(n+1) symmetric Hann window with its last (duplicate-of-first) sample dropped – the standard periodic-window trick. gwpy relies on this specific convention (via scipy.signal.get_window's default) in _truncate_impulse and TimeSeries.convolve's edge tapers, so it's reproduced exactly here rather than approximated with DSP.Windows.hanning.

GravitationalWaveData.Filtering._truncate_impulse — Method
_truncate_impulse(impulse, ntaps, window) -> Vector{Float64}

Direct port of gwpy's filter_design._truncate_impulse: window and zero the impulse response so only ntaps total non-tapered-to-zero samples remain (split between the two ends, wrapped around what will become the FIR's center once rolled in _fir_from_transfer).

GravitationalWaveData.Filtering._truncate_transfer — Method
_truncate_transfer(transfer, ncorner) -> Vector{Float64}

Direct port of gwpy's filter_design._truncate_transfer: zero the first ncorner bins (hard highpass) and smoothly taper 5 samples at each edge of the remaining array with a symmetric (sym=true-equivalent) Tukey(alpha=1) == Hann(10) window, so the transfer function doesn't have a sharp discontinuity at its own array boundaries before being inverse-FFT'd.

GravitationalWaveData.Filtering.bandpass — Method
bandpass(ts::TimeSeries, flow::Real, fhigh::Real; order::Integer=4) -> TimeSeries

Zero-phase Butterworth band-pass filter, passing frequencies in (flow, fhigh) Hz. Filter design via DSP.digitalfilter(DSP.Bandpass(flow, fhigh), DSP.Butterworth(order); fs=sample_rate(ts)), applied with DSP.filtfilt (forward-backward, so the effective order is 2*order and there is no phase distortion).

GravitationalWaveData.Filtering.notch — Method
notch(ts::TimeSeries, f0::Real; bandwidth::Real=1.0, order::Integer=4) -> TimeSeries

Zero-phase Butterworth band-stop (notch) filter, rejecting a narrow band (f0 - bandwidth/2, f0 + bandwidth/2) Hz – e.g. mains-hum removal at f0=60 (US) or f0=50 (EU). Same Butterworth+filtfilt convention as bandpass, using DSP.Bandstop + DSP.Butterworth.

GravitationalWaveData.Filtering.whiten — Method
whiten(ts::TimeSeries, psd_or_asd::FrequencySeries; kind=:asd, fduration=2.0,
       highpass=nothing, window=:hann) -> TimeSeries

Whiten ts using inverse spectrum truncation: design a length-fduration (seconds) time-domain FIR filter approximating 1/ASD(f) (via _fir_from_transfer) and convolve it with the detrended data using the overlap-save method (via _overlap_save_convolve) – not a naive FFT/divide/inverse-FFT, which would ring badly at the segment edges.

psd_or_asd supplies the spectrum to whiten against, typically from asd or psd on an off-source stretch; pass kind=:psd if you're passing a power (not amplitude) spectral density. It is linearly interpolated onto the frequency grid with spacing 1/duration(ts) before use, so it need not already be sampled at that resolution (e.g. it's fine to reuse the same off-source-estimated ASD for whitening several different on-source segments).

highpass (Hz), if given, hard-zeros the FIR's frequency response below that corner in addition to whatever 1/ASD already does there.

On stationary Gaussian input, the output has zero mean and unit variance. A segment of length fduration/2 at each end of the output is corrupted by filter settle-in (tapered instead of exact) – crop it off if that matters for downstream use.

GravitationalWaveData.Resample.resample — Method
resample(ts::TimeSeries, new_rate::Real; attenuation::Real=60, rel_bw::Real=1.0,
          Nphi::Integer=32) -> TimeSeries

Resample ts to new_rate Hz using DSP.resample's polyphase FIR resampler, with an automatically-designed Kaiser-window anti-aliasing (when downsampling) / anti-imaging (when upsampling) lowpass filter at the new Nyquist frequency – matching DSP.resample's own defaults, which are already GW-appropriate (see module docs above).

  • attenuation: stopband attenuation of the anti-aliasing filter, in dB (DSP.resample_filter's default is 60).
  • rel_bw: filter cutoff as a fraction of the new Nyquist frequency (DSP.resample_filter's default is 1.0, i.e. cutoff exactly at the new Nyquist).
  • Nphi: number of polyphase filter phases, only used for the arbitrary-ratio (non-integer rate ratio) path (DSP.resample_filter's default is 32).

t0 is preserved (see module docs: DSP.resample already compensates for the anti-aliasing filter's own group delay), and dt is set to exactly 1 / new_rate.

Returns ts unchanged (a copy) if new_rate == sample_rate(ts).
